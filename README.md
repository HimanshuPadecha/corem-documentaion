# 🛡️ Corem ORM - Official Documentation Site

This is the official documentation website for **[Corem](https://github.com/HimanshuPadecha/Corem)**, a lightweight, type-safe MySQL ORM & Migration Tool designed for modern TypeScript.

## 🚀 Tech Stack

The documentation site is built for high performance, a premium aesthetic, and an excellent developer experience using:
- **[React 19](https://react.dev/)**
- **[Vite](https://vitejs.dev/)** (Lightning-fast development server and bundler)
- **[Tailwind CSS v4](https://tailwindcss.com/)** (Utility-first styling)
- **[Framer Motion](https://motion.dev/)** (Smooth page transitions and micro-animations)
- **[React Router v7](https://reactrouter.com/)** (Client-side routing)
- **[Lucide React](https://lucide.dev/)** (Beautiful, consistent iconography)

## 💻 Running Locally

To run the documentation site on your own machine:

1. **Clone the repository:**
   \`\`\`bash
   git clone https://github.com/HimanshuPadecha/corem-orm-documentation.git
   cd corem-orm-documentation
   \`\`\`

2. **Install dependencies:**
   Using npm:
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server:**
   \`\`\`bash
   npm run dev
   \`\`\`

4. **View the site:**
   Open your browser and navigate to \`http://localhost:3000\`.

## 📁 Project Structure

- \`src/pages/\`: Contains the main page components (\`LandingPage.tsx\`, \`DocsPage.tsx\`, \`ExamplesPage.tsx\`).
- \`src/components/\`: Reusable UI components including the complex \`DocsLayout\`, \`CodeBlock\`, and shadcn/ui components.
- \`src/data/\`: Contains structured data like the sidebar navigation (\`sidebar.ts\`).
